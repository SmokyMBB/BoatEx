# Морской экзамен

Статический сайт для подготовки моториста-матроса и моториста-рулевого.

**Адрес после публикации:** https://fdmishat1.github.io/maritime-exam/

## Публикация на GitHub Pages

1. Войдите в https://github.com/fdmishat1 и создайте **публичный** репозиторий с именем `maritime-exam` (или откройте уже существующий).
2. Загрузите **содержимое этой папки** в корень репозитория: `index.html`, `questions.json`, `sw.js`, `manifest.json`, `original.pdf`, папку `pages`, `.nojekyll`. Не загружайте их внутри дополнительной папки.
3. Сделайте commit в ветку `main`.
4. В репозитории откройте **Settings → Pages → Build and deployment → Deploy from a branch**.
5. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
6. После завершения развёртывания откройте https://fdmishat1.github.io/maritime-exam/ .

## Возможности и ограничения

- 105 интерактивных вопросов из исходной базы; режим обучения, экзамен, ошибки, локальная статистика.
- 61 страница оригинального PDF и изображения страниц для справки.
- Нет серверной части, токенов, паролей или внешних API. Статистика хранится только в браузере.
- Для первого открытия нужен интернет. После первого открытия основные файлы кэшируются; изображения страниц и PDF доступны офлайн только после того, как они были открыты онлайн.
- Исходная автоматическая выборка из PDF неполная: не все вопросы переведены в интерактивный формат.
- Не публикуйте PDF в открытом репозитории, если у вас нет права на его распространение.

Локальная проверка: `python -m http.server 8000`, затем http://localhost:8000/ .
