# Морской экзамен — GitHub Pages

Адаптивный статический сайт с 105 интерактивными вопросами, проверкой ответов, режимом экзамена и просмотром исходной страницы PDF непосредственно внутри каждого вопроса.

## Обновление GitHub

1. Распакуйте ZIP.
2. В репозитории `SmokyMBB/BoatEx` замените `index.html`, `questions.json`, `sw.js`, `README.md`, `original.pdf`, `manifest.json` и папку `pages/` файлами из архива.
3. В Settings → Pages установите `Deploy from a branch`, `main`, `/(root)`.
4. Откройте https://smokymbb.github.io/BoatEx/ и обновите страницу с очисткой кэша.

## Примечания

Для вопросов с упоминанием рисунка или диаграммы страница оригинала раскрывается автоматически. Для всех остальных вопросов её можно раскрыть вручную. Показывается полная страница: это сохраняет подписи и графические элементы, но может содержать соседние вопросы. Не все вопросы 61-страничного оригинала переведены в интерактивный формат; число таких вопросов — 105.


Порядок вопросов автоматически перемешивается при каждом открытии страницы и при каждом новом запуске режима обучения, экзамена или ошибок.
